1. API Lifecycle — Bab 28A (Baru)
Setiap API endpoint wajib memiliki status lifecycle:
Status

Deskripsi

Action

DRAFT

Endpoint baru, belum siap untuk external

Hanya di dev/staging, bisa berubah
kapan saja

EXPERIMENTAL

Endpoint siap diuji oleh pengguna terbatas

Bisa berubah tanpa notice, tapi siap
pakai

STABLE

Endpoint mature, siap production

Breaking change hanya di versi baru

DEPRECATED

Endpoint masih jalan tapi akan dihapus

Minimum 12 bulan masa transisi

REMOVED

Endpoint sudah dihapus

HTTP 410 Gone

Header tambahan:
X-API-Lifecycle: STABLE
X-API-Lifecycle: DEPRECATED (Sunset: 2027-08-03)
